# 🐟学习通 · 学习助手

**视频学习辅助 · 课程队列 · AI 搜题与填答**

运行于 ScriptCat/(脚本猫）/ Tampermonkey（油猴）的学习通辅助脚本，将视频播放、任务切换、课程队列及 AI 搜题整合到一个浮窗中。支持连接 ChatGPT、DeepSeek 官方聊天网页，无需配置 API Key。

> 本脚本完全免费，所有功能均可免费使用，无需付费、订阅或激活！！！
>
> 以上声明针对本脚本；AI 服务的账号权限与使用额度以所选平台官网为准。

当前正式版：**v1.0.0**

## 功能

| 模块 | 主要功能 |
| --- | --- |
| 首页总开关 | 一键开启或关闭全部自动功能，保存设置，关闭时取消待处理请求 |
| 视频辅助 | 识别页面及嵌套框架中的视频，静音播放、暂停续播、多视频调度 |
| 任务切换 | 根据完成标记跳过已完成章节，切换顶部任务标签，支持已适配文档的逐段滚动 |
| 课程队列 | 按勾选顺序安排课程，保存队列，当前课程完成后接续下一门 |
| 自助答题 | 支持已适配的单选、多选、判断、普通填空及 UEditor 富文本填空 |
| 自动提交 | 独立开关，核对填答状态后提交，支持已适配的提交确认弹窗 |
| 文字与图片搜题 | 支持文字输入、划词、粘贴图片和选择图片；文字无有效答案时可自动截取题目重试 |
| AI 连接 | ChatGPT / DeepSeek 网页交互、固定对话复用、答案回传及请求匹配 |
| 日志与设置 | 逐题状态、运行日志、诊断导出、时间间隔设置、浮窗拖动与最小化 |

## 安装

1. 在浏览器安装并启用 **Tampermonkey/ScriptCat**。
2. 从项目 Release 下载 `chaoxing-study.user.js`。
3. 在油猴管理面板新建脚本，用下载文件的**全部内容**替换编辑器内容并保存。
4. 打开或刷新学习通课程页面，确认浮窗显示 **v1.0.0**。

更新时替换原脚本的完整内容，只保留一个启用版本，并刷新学习通与 AI 聊天页面。

## 快速开始

### 配置 AI

在浮窗的 **AI** 页面选择 ChatGPT 或 DeepSeek，打开官网并登录自己的账号。可绑定已有对话链接，后续题目复用该对话。

### 开启功能

在**首页 → 全部功能**一键开启。总开关包含自动答题、自动提交和已选课程队列，也可以在各模块单独调整。

关闭总开关会停止助手运行、取消待处理请求并停止课程队列，保留 AI 来源、时间参数和课程选择；刷新后仍保持关闭。部分功能开启时，总开关显示中间状态。

浏览器限制自动播放时，先手动播放一次，再点击助手“开始”。需要暂停自动运行时，使用助手的停止按钮或总开关。

### 安排课程

在**队列**中打开个人中心并读取已加载课程，按照希望执行的顺序勾选，再启动课程队列。文件夹中的课程需先打开文件夹加载。

任务切换以平台完成标记为依据；视频播放结束不直接等于任务完成。

### 搜题与填答

- 在**搜题**中输入文字、粘贴图片或选择图片，也可开启划词搜题。
- 在**答题**中开启章节测验 / 作业自助答题，查看题号进度和逐题结果。
- 已有答案不会覆盖；无有效答案或填入失败时显示异常。
- 自动提交有独立开关；存在异常或未识别的题目时，不将其视为已完成。

图片最多 **3 张**，总大小不超过 **8 MB**。AI 处理期间保持课程页和助手打开的聊天页可用。

## 时间设置

| 设置 | 最小值 | 建议值 |
| --- | --- | --- |
| 切换前等待 | 0.1 秒 | 3 秒 |
| 自助答题填入间隔 | 0.1 秒 | 3 秒 |
| 同一多选题选项间隔 | 0.1 秒 | 0.3 秒 |

这些设置控制操作间隔，附件上传、AI 回答及页面加载仍需等待实际就绪。

## 兼容性说明

- 支持已适配的学习通页面结构；特殊题型、分页试卷、自定义阅读器或网页改版可能需要进一步适配。
- 部分题目使用专用字体，复制出的文字可能与画面不同。脚本提供题目区域图片重试，但不具备通用字体解码能力。
- 图片区域通过 html2canvas 渲染，跨域图片、字体或样式可能影响结果。
- AI 答案不保证正确；浏览器后台休眠、网络异常及网站限制可能中断流程。

## 数据说明

设置、队列、对话链接与临时请求保存在油猴存储中。发起搜题后，题目和附件会发送到所选 AI 服务的聊天页面；聊天记录由该平台保存。脚本不需要 API Key，也不读取登录密码。
