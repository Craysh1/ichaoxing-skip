# 学习通 · 学习助手

一个运行在浏览器中的 Tampermonkey（油猴）脚本，将视频播放辅助、课程队列、视频弹题、文字与图片搜题集中在一个可拖动的浮窗中。

当前版本：**v0.6.0**  
项目仓库：[Craysh1/-](https://github.com/Craysh1/ichaoxing-skip)

AI 搜题通过 **ChatGPT / DeepSeek 官方聊天网页**完成，使用用户自己的登录账号，无需配置 API Key。

## 功能概览

| 板块 | 功能 |
| --- | --- |
| 首页 | 查看当前视频、播放状态、进度和已完成任务点，启动或停止助手 |
| 队列 | 读取个人中心已加载的课程，按勾选先后保存执行顺序，查看当前页面的视频 |
| 日志 | 查看带时间和级别的运行记录，清空日志、导出诊断信息 |
| 答题 | 识别视频中的文字弹题，搜题后匹配选项，可单独开启自动提交 |
| 搜题 | 输入文字、划词填入、粘贴剪贴板图片或选择图片进行搜题 |
| AI | 选择 ChatGPT / DeepSeek、打开官网登录、绑定固定对话链接 |
| 设置 | 配置静音、暂停续播、章节切换、自动搜题、自动提交及页面选择器 |

### 视频播放辅助

- 自动发现页面及嵌套框架中的视频，支持静音播放。
- 仅在检测到暂停时尝试恢复播放，相邻尝试至少间隔 2.5 秒，避免持续重复调用播放。
- 识别到视频弹题、解码错误或播放结束时，不强行续播。
- 根据页面上的任务完成标记判断是否切换下一节，支持中文“下一节”和英文“Next”等入口。
- 播放结束或进度达到 90% 本身不会被视为任务完成。

### 课程队列

- 从个人中心已加载的课程卡片读取名称和课程链接。
- 按**勾选先后**执行，取消后重新勾选会移到队尾。
- 保存课程列表和顺序，刷新后仍可使用。
- 支持当前课程结束后接续队列，也支持从队列第一门课程开始。
- 队列由启动它的标签页执行，避免多个标签页同时切换课程。

跨课程切换目前属于需要页面适配的功能：只有识别到章节列表全部完成、当前视频任务全部完成、无待答题目且没有可用的下一节入口，连续确认后才尝试切换。目录结构未知或入口无法识别时可能停留等待，提供手动确认入口。

### 文字与图片搜题

- 支持文字输入和划词填入搜题框。
- 在搜题输入框按 `Ctrl+V` 粘贴剪贴板图片，或点击“选择图片”。
- 支持 PNG、JPEG、WebP、GIF，每次最多 **3 张**，总大小不超过 **8 MB**。
- 图片可以预览、移除，也可以只传图片而不输入文字。
- 检查附件预览和上传状态后再尝试发送。

### AI 网页连接

- 答题与搜题复用固定对话，目标名称为 **“学习通刷课搜题”**。
- 查找已加载的同名对话；未找到时尝试建立对话、重命名并保存实际链接。也支持手动绑定已有对话。
- 题目填入后检查发送结果；原题仍在输入框且未确认发送时，间隔至少 6 秒有限重试，最多 3 次。
- 使用请求编号匹配回答，避免将其他题目的答案回填到当前题目。
- 自动发送或读取失败时，提供复制题目和手动粘贴 JSON 回答的入口。
- 回传后尝试关闭本次由助手打开的聊天标签页并返回课程页面，实际焦点切换受浏览器控制。

每题都会提示 AI 独立作答、忽略前题。**这不会清除同一对话的历史上下文，也不保证减少推理时间。**

### 浮窗交互

白色主题，支持拖动顶部标题栏移动窗口并记住位置；最小化后显示在浏览器左下角。界面更新尽量保留现有控件，减少滚动条和布局抖动。

## 安装与更新

1. 在浏览器中安装并启用 Tampermonkey。
2. 打开最新的脚本文件，复制所有。
3. 打开油猴管理面板，新建脚本，将文件的全部内容粘贴进去并保存。
4. 打开或刷新学习通页面，确认助手浮窗出现。
5. 如需 AI 搜题，在助手的“AI”板块打开官网，并自行登录账号。

更新时，用新版完整内容替换原脚本。**只保留一个启用版本**，并刷新课程页、个人中心和聊天页。旧版尚未完成的搜题请求建议取消后重新发起。

## 快速开始

### 播放视频

进入视频学习页面后，助手会尝试识别并播放视频。浏览器禁止自动播放时，请先手动播放一次，再点击助手“开始”。

需要停止时，请点击助手的 **“停止”**。开启暂停续播后，直接点击播放器暂停可能会触发恢复播放。

### 安排课程顺序

1. 打开“队列”，点击“打开个人中心 / 读取课程”。
2. 等待课程卡片加载。文件夹内的课程需要先打开文件夹。
3. 按希望执行的顺序勾选课程，列表中的编号表示队列顺序。
4. 回到正在学习的页面，点击“当前课程完成后执行队列”；也可在个人中心点击“开始课程队列”。

### 搜题与视频弹题

1. 在“AI”中选择服务并完成官网登录。
2. 在“搜题”输入文字或添加图片，点击搜索。文字输入支持 `Enter` 搜索、`Shift+Enter` 换行。
3. 保持课程页和助手打开的聊天页可用，等待回答回传。
4. 视频弹题可在“答题”中点击“搜题并填入选项”。

“视频弹题自动搜题并填答”和“填答后自动提交答案”是两个独立开关，**默认均关闭**。开启自动提交后，只有当前题目匹配、选项状态确认且提交入口唯一时才尝试提交。

自动填答适配文字形式的单选、判断和多选视频弹题。手动图片搜题用于显示结果，不会自动匹配网页上的未知答题控件。

## 数据与权限

脚本运行于学习通相关页面，以及 ChatGPT、DeepSeek 聊天网页。

- 使用油猴存储保存设置、课程队列、对话链接和临时搜题请求。
- 使用标签页存储识别执行队列的标签页；使用标签页打开与关闭功能连接聊天网页。
- 题目和图片会发送给所选 AI 服务。手动搜题在点击搜索后发送；开启视频弹题自动搜题后会自动发送识别到的题目。
- 请求完成或取消后清理相应的临时请求；聊天历史中的内容和附件仍由 AI 官网保存。
- 普通聊天标签页不进行回答采集，只有携带有效请求编号的助手标签页运行回传流程。
- 脚本不读取密码、Cookie 或登录令牌，不调用隐藏聊天接口。
- 会员信息没有自动读取功能，账号权益与可用额度以 AI 官网显示为准。

## 已知限制

- 学习通及 AI 网站改版可能影响视频识别、课程入口、附件上传、发送按钮和回答读取。
- 课程队列只读取已加载的课程；完整章节目录的完成状态仍需按实际页面验证。文档、测验及未知入口可能需要手动处理。
- 视频弹题中的图片或画布不会自动截图，填空题和部分自定义选项控件尚未适配。
- AI 生成的答案可能错误；点击提交不代表页面判定答对。
- 固定对话自动命名依赖官网菜单，失败时需要手动命名或绑定链接；未加载到侧栏的同名对话不一定能被发现。
- 浏览器后台冻结、系统休眠、网络异常可能中断流程，自动返回课程页也可能受焦点策略限制。
- 已完成模拟浏览器回归测试，覆盖续播、弹题回填、发送重试、图片传递和队列顺序等场景；这不等同于所有学校页面与真实登录账号环境的兼容性验证。

## 常见问题

**题目填进聊天框了，但没有发出去？**

确认已登录、附件上传已完成，等待有限重试。仍未发送时，可在聊天网页手动点击发送；回答回传仍会继续监听。

**AI 已回答，但没有回填？**

先检查课程页和聊天页是否都已刷新为同一版本。无法自动读取时，展开聊天助手中的“手动粘贴回答回传”，粘贴本次完整 JSON 回答。当前题目已经变化或助手已停止时，不会应用旧题答案。

**视频完成了，为什么没有换课？**

单个视频任务完成与整门课程完成不同。检查章节是否仍有未完成任务、目录是否完整加载、队列是否已启动。无法识别完成状态时，可在核实课程完成后使用手动确认入口。

**出现“视频文件损坏”怎么办？**

暂停助手，尝试切换视频线路或刷新页面，并检查停用脚本后是否仍然出现。可通过日志中的诊断功能记录问题，不能仅凭该提示确定故障原因。
